# Enterprise Web Development Survival Guide

## CNA • September 2026

Welcome to the dumpster fire.

Instead of relearning everything every six months, I'm putting my notes, projects, resources, cheat sheets, course summaries, and random discoveries in one place.

Future Brenda can thank Present Brenda later.
