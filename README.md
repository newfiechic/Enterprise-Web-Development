This repository is the learning side of a larger project.

Alongside the Enterprise Web Development program, I am developing **[Northframe](https://github.com/newfiechic/Northframe-Public)**, an independent project focused on systems thinking, human-centred analysis, research, practical problem-solving, and finding the gaps that make projects harder to understand, use, or build.

Northframe looks at projects, products, processes, and digital systems as whole systems rather than a pile of disconnected parts.

This repository gives me the technical side to keep building underneath that.

As I move through the program, I want to connect what I learn about programming, websites, databases, APIs, e-commerce, usability, accessibility, business, project design, and technical communication back to the kinds of problems Northframe is built to examine.

Basically:

**This repo is where I learn how the machine works.**

## Rules

* Document everything.
* Comment code when Future Brenda might swear at Past Brenda.
* If something takes four hours to figure out, write it down.
* If something takes four minutes to figure out, write it down anyway.
* If I solve the same problem twice, the second time better result in documentation.
* Google is not cheating.
* Documentation is not cheating.
* Looking at my own old code is definitely not cheating.
* Stack Overflow is basically a textbook written by thousands of exhausted people.
* ChatGPT is the emotional support debugger.
* "I used to know this" is not useful documentation.
* "It worked somehow" is also not useful documentation.
* Do not trust Past Brenda to remember why she did anything.
